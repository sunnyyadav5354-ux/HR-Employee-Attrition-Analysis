# HR Employee Attrition Analysis
## 📌 Project Overview

This project analyzes employee attrition and workforce patterns using PostgreSQL.
The analysis focuses on understanding employee turnover across departments, salary, tenure, engagement, diversity, compensation, job levels, and bonus percentages.

## 🎯 Business Objective
The objective of this project is to identify patterns in employee attrition and understand the factors associated with employee turnover.
Key questions analyzed include:

- Which departments have higher attrition?
- How does salary relate to attrition?
- Does employee tenure affect attrition?
- What are the employee engagement patterns?
- How does attrition vary by gender, race/ethnicity, and veteran status?
- How do job levels, compensation, and bonus percentages relate to attrition?
